Four rules

The robot starts on a blank tape. Each step, it reads the square under it, writes a 0 or 1, moves one square left or right, and follows the rule’s next state. If you choose H, the robot writes, moves and then stops. Changing any rule restarts the run.

How the checker decides

This robot has two working states, A and B, and writes 0s and 1s on an endless tape that starts blank. We stop after at most 100 steps. The rules stay the same wherever the robot stands on the tape.

A halt means a rule sent the robot to H. A repeat means its state and the complete pattern of 1s around it match an earlier step, so it will loop forever. If neither happens by step 100, it is unresolved by this checker.

For the standard blank-tape model used here, with two states, two symbols and a left or right move on every step, S(2) = 6; MathWorld lists the same value. A robot still running at step 100 is unresolved by this checker. The standard result separately shows it never halts. The checker does not use that result, so you can see what a simple test finds on its own.

Why a matching tape proves a loop

Every square outside the complete set of 1s is blank, and each rule acts the same way wherever the robot stands. When the state and the pattern around the robot match an earlier step, the next steps must match too, shifted along the tape.

The checker can miss other ways a robot runs forever. The growing trail has a halt rule but keeps reaching fresh blank squares, so it never uses that rule.
