What did we actually learn?

A repeated whole situation is evidence.

A halt is witnessed when a rule sends the robot to H. A translation cycle needs the same working state and the same entire finite set of 1s at the same offsets from the head as at an earlier step. The absolute head position can differ. Because the untouched tape is 0 everywhere else and the rules work the same at every position, every later action repeats with that shift. It cannot reach H in a later cycle if it did not reach H in the first one.

After 100 steps without either witness, the answer is unknown at the limit. A growing trail may look endless, but a cutoff does not prove it. This is a bounded teaching simulation, not a solver for arbitrary machines or a proof about BB(6).
